# 📊 Conversion Pipeline Dashboard | M.S Excel
Interactive Excel dashboard analyzing agent performance, call conversion, deal value and monthly trends.

## Project Overview
Conversion Pipeline is an interactive Excel dashboard designed to analyze sales-agent calling activity, conversion performance, and deal value across January–December 2024.
The dashboard evaluates the complete conversion pipeline:
Calls → Reached → Closed → Value
The objective is to transform raw calling data into meaningful KPIs and actionable business insights.

## Dataset
The dataset contains 312 records across 26 sales agents for the year 2024.

## Key Insights
. 18,300 calls were made during the year, with 3,619 calls successfully reached.
. The reached-to-deal conversion rate was approximately 36.2%.
# The 36.2% conversion rate is calculated as Deals Closed ÷ Calls Reached.
. Molly closed the highest number of deals with 103 deals.
. Mimi generated the highest total deal value at approximately $50.5K.
. February recorded the highest number of closed deals with 118.
. March generated the highest monthly deal value at approximately $60.1K.
. Average call duration remained relatively stable throughout the year.
. Call drop rate remained close to 5% across the year.

## Dashboard Analysis
The dashboard provides:
. Agent-wise performance analysis
. Monthly conversion trends
. Deal value analysis
. Average call duration analysis
. Call drop rate monitoring
. KPI-based performance tracking
